# Screenshots

These images show the native PandaBert interface with fictional sample tasks, projects and profile labels. They are UI illustrations, not evidence of live account connections, running agents or GitHub synchronization.

- `attention.jpg` (0.3.0): a pinned active task and a question needing attention.
- `background.jpg` (0.3.0): the background list with active, waiting and reviewed tasks.
- `task-details.jpg` (0.3.0): a sample question, its context and task controls.

- `notification-glow.jpg` (0.3.0): the newest attention item with the softer outline and stronger lavender halo. This is a still frame of the 30-second animation.

Captured on macOS from an isolated copy of the app using the production panel views. The screenshot copy replaces live collection with an in-memory fixture and uses a separate data directory. No production UI styling was changed for these captures. The user's running PandaBert instance and its settings were preserved.
